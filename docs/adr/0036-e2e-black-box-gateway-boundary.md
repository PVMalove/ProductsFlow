# 0036. E2E проверяют систему только через Gateway

E2E-стек поднимается session-scoped pytest fixture из отдельного Compose-описания и предоставляет только E2E-only Nginx Gateway. Gateway применяет strict allow-list публичных путей и передаёт авторизационные и forwarded-заголовки upstream-сервисам. Тесты обращаются к неизменённым публичным BFF-путям через этот Gateway; готовность устанавливается HTTP-probes через него, включая readiness seeded admin в Support, а не прямым доступом к сервисам, БД или брокеру. Стек удаляется fixture через `down -v`, а каждый сценарий создаёт уникальные данные, поэтому тесты не зависят от порядка выполнения и не требуют privileged cleanup API.
