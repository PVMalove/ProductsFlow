# 0007. Вторая версия API — только для новых эндпоинтов, без дублирования первой

Первая версия API (`/api/v1`) уже обслуживает аутентификацию, CRUD Товаров и управление Пользователями. Новый эндпоинт публичной ссылки на Картинку товара (см. `CONTEXT.md` → «Картинка товара») должен появиться, не меняя контракт `/api/v1` для существующих клиентов. Вместо полного зеркалирования всей текущей поверхности API под новым префиксом вводится отдельный роутер второй версии (`/api/v2`), содержащий только новый эндпоинт. Существующие роутеры (`auth`, `products`, `users`) остаются подключены исключительно к `/api/v1` — параллельного подключения ко второй версии для них нет.

## Considered Options

- **Полное дублирование**: развернуть все существующие роутеры и под `/api/v1`, и под `/api/v2`, добавив новый эндпоинт только во вторую копию. Отклонено — раздувает поверхность API и число обслуживаемых путей вдвое ради одного нового эндпоинта; каждое будущее изменение существующих роутеров пришлось бы либо дублировать в обе версии, либо решать, какая версия «настоящая».
- **Точечное версионирование одного эндпоинта** (например, суффикс `/v2` только у нового пути внутри общего роутера продуктов) вместо отдельного префикса на уровне приложения. Отклонено — версионирование в проекте уже устроено на уровне `APIRouter(prefix="/api/v1")` (`app/main.py`); вводить второй, несовместимый механизм ради одного эндпоинта усложнило бы код без выгоды.

## Consequences

- `/api/v1` не меняется и не растёт: новые возможности, не обязанные быть обратно совместимыми с первой версией, естественно попадают только в `/api/v2`.
- Общая логика проверки видимости Товара не дублируется вместе с роутерами — выносится в модуль, общий для роутера Товаров (`/api/v1`) и нового роутера (`/api/v2`).
- Тестовый HTTP-клиент (`tests/conftest.py`), автоматически проставляющий префикс `/api/v1` для уже известных путей первой версии, не подставит его для путей второй версии — в интеграционных тестах эндпоинта Картинки товара путь должен указываться полностью, с префиксом `/api/v2`.
