# 0037. Имена Compose-контейнеров определяет проект

Общий Compose не задаёт `container_name`: Docker Compose формирует имена из project name и service name. Это позволяет E2E fixture владеть изолированным стеком и удалять его volumes без конфликта с локально запущенным dev-стеком; внутренний DNS по имени сервиса остаётся неизменным.
