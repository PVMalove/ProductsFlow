# 0035. Самостоятельное удаление пользователя

Удаление учётной записи доступно её владельцу через аутентифицированный `DELETE /api/v1/users/me` и возвращает `200 {"data": null, "meta": {}}`. Это необратимая операция, отдельная от деактивации: identity заменяет Пользователя анонимизированным надгробием с терминальным `is_deleted`, публикует `user.deleted.v1` через transactional outbox, а Support сохраняет анонимизированные Тикеты и переводит активные Тикеты в `CLOSED`. Tombstone нельзя активировать; его прежний bearer token получает `403 FORBIDDEN`. Публичный контракт выбран вместо тестовой подмены деактивацией, чтобы весь путь удаления был законным наблюдаемым поведением системы и не смешивал разные доменные состояния.
