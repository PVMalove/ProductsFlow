# 0003. Проверять JWT статическим публичным ключом

> **Поглощено консолидированным [ADR 0005](../../../../../docs/adr/0005-security-auth-actor-contract.md)** корневой базы ADR — фактическое поведение support (статический ключ, не JWKS) зафиксировано там же как текущее правило для этого сервиса. Текст ниже сохранён как исторический источник обоснования.

Support получает RS256 public key из своей конфигурации при старте и валидирует
подпись и срок действия токена локально. `IdentityClient` не применяется для
этого пути, поскольку его JWKS-refresh выполняет HTTP-запросы, несовместимые с
требованием полностью stateless auth без сетевой проверки.
