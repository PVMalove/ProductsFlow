# 0001. Сохранять анонимизированные тикеты при удалении пользователя

> **Поглощено консолидированными [ADR 0009](../../../../../docs/adr/0009-support-service-domain-model.md)** (доменная часть) **и [ADR 0012](../../../../../docs/adr/0012-support-service-event-integration.md)** (событийная часть) корневой базы ADR. Текст ниже сохранён как исторический источник обоснования.

При получении `user.deleted` Support анонимизирует ссылку автора и переводит
активные тикеты в `CLOSED`, добавляя системное сообщение. Это сохраняет историю
и аудит обращений без сохранения связи с удалённым пользователем; hard-delete
терял бы операционный контекст, а анонимизация без закрытия оставляла бы
необрабатываемые активные тикеты.
